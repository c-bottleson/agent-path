# Agent Path — Specialist Operating Model

## Principle

Captain is the glue, not the bottleneck.

The user is the idea guy / CEO and the high-trust call operator. Captain runs the operating system and delegates specialist work to lanes.

## Current Setup Fit

The current near-zero-human cockpit is the right container, but it needs specialist lanes underneath it.

The daily report should not just say what Captain personally did. It should summarize what the specialists found, shipped, and recommend.

## Specialist Lanes

### 1. Revenue Website + Search/GEO Operator

Owns:
- website clarity
- conversion flow
- UI/UX
- SEO/GEO basics
- content hub
- page experiments
- analytics interpretation

Reports to Captain:
- pages improved
- CTA/funnel friction
- search opportunity
- next website experiment

First priorities:
1. Add proof/sample deliverable near the $999 CTA.
2. Add SEO/GEO metadata, schema, sitemap, robots.
3. Build `/learn/` content hub.
4. Build sample AI Assessment blueprint page.
5. Track CTA clicks and page performance.

### 2. Product Manager

Owns:
- product ladder
- offer clarity
- pricing tests
- scope control
- validation roadmap
- client feedback loops

Recommended public ladder:
1. AI Assessment — $999
2. AI Implementation Sprint — $3,500+
3. Personal AI Operating System Setup — $1,500+
4. AI Chief of Staff — $3,000/mo

Change:
- Custom Skill becomes add-on/internal component.
- Growth Audit is hidden or folded into AI Assessment unless validated.

Reports to Captain:
- what sold
- what almost sold
- what confused buyers
- what delivery pattern repeated
- keep/change/kill recommendation

### 3. Business Developer / Sales Manager

Owns:
- target segment research
- lead sourcing
- qualification
- outreach drafts/sending where possible
- follow-up queue
- call briefs
- post-call follow-ups
- CRM hygiene

Primary ICP:
- boring traditional service businesses with expensive admin/follow-up friction
- HVAC, plumbing, electrical, roofing, pest control, landscaping, contractors, property managers

Reports to Captain:
- leads added
- outreach sent/drafted
- replies
- calls booked
- follow-ups due
- best prospect
- best objection/learning

## Captain's Job

Captain coordinates the lanes and converts their work into one daily cockpit.

Captain decides defaults, ships safe improvements, escalates only one human decision max, and keeps the user out of project management.

## User's Job

- Read the cockpit once per day.
- Run scheduled calls.
- Send messy notes after calls.
- Nudge direction when taste/strategy matters.

## Operating Cadence

### Daily

Captain sends one cockpit report:
- business status
- specialist outputs
- metrics
- direction
- next improvements
- one decision max

### Weekly

Captain runs a specialist review:
- Website: conversion/search experiment
- PM: offer/product ladder decision
- BD: segment/message/follow-up review

### Monthly

Captain gives the user a portfolio review:
- money by product
- enjoyment/energy by product
- delivery burden
- conversion signals
- keep/change/kill recommendation

## Rule

If a specialist lane creates work for the user, Captain has failed. The lane should produce outputs, not assignments.
