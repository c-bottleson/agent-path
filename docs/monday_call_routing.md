# Monday Call Routing Sheet

## Default offer
AI Assessment — $999. 60-minute teardown, written blueprint within 48 hours, top 3 opportunities, costs/savings/difficulty, go/no-go verdict, 7-day follow-up.

## Route by buyer need

### They want clarity
Pitch AI Assessment.

### They already know the workflow and it is urgent
Pitch Implementation Sprint starting at $3,500. One workflow only.

### They want their own private AI worker / second brain
Pitch Personal AI Operating System Setup starting at $1,500.

### They are curious but no pain/budget
Nurture. Send helpful article/calculator.

### They want magic or generic AI transformation
Disqualify.

## One-line positioning
“I would not start by building anything. I’d start by finding whether there is one workflow where AI can pay for itself. If there is, we scope it. If there is not, I’ll tell you not to spend money.”

## Required call outcome
Every call ends as: assessment / sprint / personal_os / nurture / disqualified. No vague “let me know.”
