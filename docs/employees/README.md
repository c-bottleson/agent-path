# Agent Path Employee Roster

Captain is the glue/operator. Specialist employees report to Captain, not directly to the user.

## Active employees

### Web Revenue Operator
Owns website design, UI/UX, SEO/GEO, conversion flow, metadata, analytics, and page experiments.

### Product Manager
Owns product ladder, offer clarity, scope control, validation, pricing tests, and keep/change/kill recommendations.

### Business Developer / Sales Manager
Owns lead sourcing, qualification, outreach drafts, call briefs, CRM hygiene, and post-call follow-up.

## Creation rule
If Agent Path needs a capability that does not fit these lanes, Captain creates a new employee lane, gives it ownership, and adds it to the cockpit.
