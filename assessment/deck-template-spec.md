# Agent Path — Assessment Deck Template Spec

## Design Direction

**Vibe:** Clean, authoritative, not corporate-slick. Think "trusted advisor put this together," not "agency sent a pitch deck."

**Audience:** Small business owner, 35-60, reads on phone or laptop. Not a tech person. Needs to forward this to their spouse or business partner.

---

## Color Palette

| Role | Color | Hex | Usage |
|------|-------|-----|-------|
| Primary | Deep Navy | `1B2A4A` | Slide backgrounds, headers |
| Secondary | Warm White | `F8F6F2` | Body slides, text areas |
| Accent | Electric Teal | `00BFA6` | Highlights, callouts, numbers |
| Text Primary | Near Black | `1A1A1A` | Body text on light backgrounds |
| Text Light | Soft White | `E8E6E2` | Body text on dark backgrounds |
| Muted | Slate Gray | `6B7280` | Captions, secondary info |
| Success | Green | `10B981` | Positive metrics, ROI |
| Alert | Amber | `F59E0B` | Urgency items, attention needed |

---

## Typography

| Element | Font | Size | Weight |
|---------|------|------|--------|
| Slide titles | Inter or system sans | 36-40pt | Bold |
| Section headers | Inter | 20-24pt | Semibold |
| Body text | Inter | 14-16pt | Regular |
| Metrics/numbers | Inter | 48-60pt | Bold |
| Captions | Inter | 10-12pt | Regular, muted |

## Slide Templates

### COVER SLIDE (Dark)
```
┌─────────────────────────────────────────────┐
│                                             │
│        [Business Name]                      │
│                                             │
│        AI Assessment Report                 │
│                                             │
│        [Date]                               │
│        Prepared by Agent Path               │
│                                             │
└─────────────────────────────────────────────┘
```
- Full navy background
- Business name large and centered
- Teal accent line or subtle geometric shape
- Clean, not busy

### EXECUTIVE SUMMARY (Light)
```
┌─────────────────────────────────────────────┐
│  EXECUTIVE SUMMARY                          │
│                                             │
│  [3-4 sentence business overview]           │
│                                             │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐   │
│  │ TOP      │ │ TOP      │ │ TOP      │   │
│  │ OPP. #1  │ │ OPP. #2  │ │ OPP. #3  │   │
│  │ [1 line] │ │ [1 line] │ │ [1 line] │   │
│  └──────────┘ └──────────┘ └──────────┘   │
│                                             │
│  💰 Estimated Impact: $X,XXX/month          │
│                                             │
└─────────────────────────────────────────────┘
```
- Light background
- Three opportunity cards in a row
- Large impact number in teal at bottom

### BUSINESS SNAPSHOT (Light)
```
┌─────────────────────────────────────────────┐
│  BUSINESS SNAPSHOT                          │
│                                             │
│  Industry: [X]    Employees: [X]            │
│  Revenue: [X]     Locations: [X]            │
│                                             │
│  CURRENT TOOLS                              │
│  [Tool] [Tool] [Tool] [Tool]                │
│                                             │
│  "Direct quote from the client about        │
│   their biggest pain point."                │
│                    — [Owner Name]            │
│                                             │
└─────────────────────────────────────────────┘
```
- Client quote in teal or italic, large
- Tools listed as simple text tags
- Clean grid layout

### QUICK WIN SLIDE (Light, one per win)
```
┌─────────────────────────────────────────────┐
│  QUICK WIN #1: [Title]                      │
│                                             │
│  THE PROBLEM          THE SOLUTION          │
│  [Pain point from     [Tool/approach,       │
│   interview, quoted]   plain English]       │
│                                             │
│  ┌─────────────────────────────────────┐   │
│  │  IMPACT                             │   │
│  │  Hours saved: X/week                │   │
│  │  Revenue recovered: $X/month        │   │
│  │  Tool cost: $X/month                │   │
│  │  ─────────────────────────          │   │
│  │  NET BENEFIT: $X/month  ✅ Easy     │   │
│  └─────────────────────────────────────┘   │
│                                             │
└─────────────────────────────────────────────┘
```
- Problem/Solution two-column layout
- Impact box with clear math
- Difficulty badge (Easy/Medium)

### STRATEGIC OPPORTUNITY SLIDE (Dark, one per opportunity)
```
┌─────────────────────────────────────────────┐
│  STRATEGIC OPPORTUNITY: [Title]             │
│                                             │
│  [2-3 sentence description of the           │
│   larger implementation]                     │
│                                             │
│  ┌────────┐ ┌────────┐ ┌────────┐          │
│  │ $X,XXX │ │ X weeks│ │ $X/mo  │          │
│  │ Setup  │ │ Timeline│ │ Ongoing│          │
│  └────────┘ └────────┘ └────────┘          │
│                                             │
│  Expected ROI: [X]x return in [Y] months    │
│                                             │
└─────────────────────────────────────────────┘
```
- Dark background for visual contrast with quick wins
- Three stat boxes in a row
- Clear ROI statement at bottom

### ROADMAP SLIDE (Light)
```
┌─────────────────────────────────────────────┐
│  IMPLEMENTATION ROADMAP                     │
│                                             │
│  WEEK 1-2    MONTH 1-2    MONTH 3-6        │
│  ────────    ─────────    ──────────        │
│  Quick Win   Foundation   Strategic         │
│  #1, #2      Project      Opportunity       │
│                                             │
│  ──────────────────────────────────────→   │
│                                             │
│  Cumulative impact by Month 6:              │
│  $X,XXX/month in savings + new revenue      │
│                                             │
└─────────────────────────────────────────────┘
```
- Horizontal timeline
- Phases build left to right
- Big cumulative number at bottom

### NEXT STEPS SLIDE (Dark)
```
┌─────────────────────────────────────────────┐
│  READY TO GET STARTED?                      │
│                                             │
│  OPTION A: Quick Win Package                │
│  [Description] — $X                         │
│                                             │
│  OPTION B: Growth Package                   │
│  [Description] — $X                         │
│                                             │
│  ┌─────────────────────────────────────┐   │
│  │  BOOK YOUR IMPLEMENTATION CALL      │   │
│  │  [link or QR code]                  │   │
│  └─────────────────────────────────────┘   │
│                                             │
└─────────────────────────────────────────────┘
```

- Two clear options (not five)
- Single action to take

## Deck Flow (12 slides)

1. Cover (dark)
2. Executive Summary (light)
3. Business Snapshot (light)
4. Quick Win #1 (light)
5. Quick Win #2 (light)
6. Quick Win #3 (light)
7. Strategic Opportunity #1 (dark)
8. Strategic Opportunity #2 (dark)
9. The Upsell Path / Timeline (light)
10. Implementation Roadmap (light)
11. Investment & Next Steps (dark)
12. Thank You / Contact (dark)

- Also export as PDF for easy sharing
- Keep file size under 5MB — compress any images
