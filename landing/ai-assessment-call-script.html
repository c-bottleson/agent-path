0:00 - Opening frame

Today is part assessment, part working session. I’m going to learn how you work, find the highest-value places AI can help, and teach you a prompting workflow you can reuse after the call. We are not trying to boil the ocean. We are looking for a few repeatable wins.

5:00 - Work map questions

  • Walk me through a normal week. Where do things slow down?
  • What work repeats every week or month?
  • Where do you copy/paste, summarize, rewrite, compare, research, or follow up?
  • What decisions do you make from messy information?
  • What do you avoid because it is annoying, not because it is hard?
  • If Claude saved you 3 hours/week, where would you want those hours back?
Listen for
Repeating work, messy inputs, high-trust writing, decision support, follow-up tasks, document review, customer comms.

10:00 - Opportunity scoring

Good AI fit

  • Text-heavy
  • Repeatable
  • Has examples
  • Clear success criteria
  • Low downside if reviewed

Bad first AI fit

  • High legal/financial risk without review
  • No clear source material
  • Requires real-time system access not set up
  • One-off novelty task
Score each workflow 1-5: Time saved · Frequency · Pain · Quality impact · Ease to test Pick the highest combined score as the first use case.

15:00 - Teach meta prompting

The trick is not writing the perfect prompt first. Start with a rough idea and ask Claude to help build the prompt. That does two things: it gives Claude better instructions, and it forces you to clarify what you actually want.

Use this live

I have a vague idea: [describe messy goal]. Before you answer, help me turn this into a strong prompt. Ask me up to 5 questions if needed. Then give me: 1. A clear prompt I can reuse 2. The assumptions you made 3. What a good output should include 4. A shorter version of the prompt

22:00 - Build one reusable workflow

  1. Pick one real task from his work.
  2. Collect one real example or describe the normal input.
  3. Run the meta prompt.
  4. Turn Claude’s improved prompt into a saved reusable prompt/project instruction.
  5. Define success: faster, clearer, less rework, better follow-up, fewer missed details.

28:00 - Close and next steps

The first goal is not to make Claude magical. It is to make one useful workflow reliable. Once that works, we add the next one. The setup matters because Claude gets much better when it has the right context, examples, and boundaries.
