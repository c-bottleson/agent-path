Install Call Addendum

Jackson's Karpathy Second Brain

Use this after the standard Hermes install call. The goal is not to impress him with integrations. The goal is to make capture, retrieval, and tiny action easier than doing nothing.

Positioning Script

"Jackson, we're not setting up a productivity app you have to maintain. We're setting up a place where you can throw thoughts, links, school stuff, project ideas, and reminders without organizing them first. The agent's job is to catch it, sort it, remind you at the right time, and help make tomorrow easier."

V1 Rule

Keep it simple. Telegram first. Hermes native memory/files/reminders. No calendar, no NotebookLM automation, no Notion dashboard until usage is proven.

Simple Architecture

Telegram Capture
Hermes Profile
Memory + Files
Cron Nudges
Weekly Review

What to Install / Configure

  • Fresh Hermes profile for Jackson.
  • Telegram gateway with his private bot.
  • Memory enabled for stable facts and preferences.
  • File tools for notes, source packs, and summaries.
  • Session search for recall.
  • Cron jobs for morning/evening nudges.
  • Web search if he wants research capture.
  • Skills for capture, review, nudges, and study-pack export.

What NOT to Install Yet

  • No Google Calendar / iCloud Calendar in v1.
  • No NotebookLM API/MCP automation.
  • No Notion sync as primary interface.
  • No complex dashboard until we see real capture behavior.
  • No outbound communication agent.

Live Call Flow

1

Open with the outcome

"The win is simple: when something crosses your mind, you send it here. Later, you can ask for it back. If the system does that reliably, we won."
2

Set capture categories

Create these buckets: Inbox, School, Mechanical Engineering, Projects, Game Design, Watch/Product Ideas, Links/Research, Tasks, Reminders, Parking Lot.
3

Explain behavior layer

"This is partly a memory system and partly an environment-design system. If something matters, we'll make it easier to start. If something keeps derailing you, we'll add friction to it."
4

Create first nudge routines

Add morning hook, evening setup, and Sunday review. Keep each one short enough that it doesn't feel like homework.
5

Run the first captures

Have Jackson send 5 real messages: one school thought, one project idea, one link, one task, one reminder.

Behavioral Economics Priority

Reduce friction Timely nudges If-then plans Choice architecture Tiny starts Tomorrow hook
  • Make the good behavior easier than the default.
  • Prompt only when action is realistic.
  • Prefer one tiny action over a motivational speech.
  • Convert vague goals into room setup, reminders, and scripts.

Example Nudges

  • Morning: "One win today: open the CAD file for 5 minutes."
  • Tomorrow hook: "After breakfast, sketch the ugly first version of the watch idea."
  • Room setup: "Put your alarm in the bathroom so you're already near the shower."
  • Friction: "Put distracting apps one folder deeper tonight."
  • If-then: "If I finish coffee, then I send one idea to Jarvis."

First Cron Jobs

Morning nudge — 8:30 AM
Ask Jackson for one tiny win, one exciting thing, and one first action.

Evening setup — 9:30 PM
Ask what he wants to make easier tomorrow. Suggest one room/environment setup.

Sunday review — 6:00 PM
Summarize captures, open loops, wins, reminders, and one friction fix for next week.

48-Hour Validation

  • Jackson sends 10 captures.
  • Hermes files them into the right buckets.
  • Jackson asks for one item later and gets it back.
  • He tries one environment nudge.
  • He has one tomorrow hook he actually cares about.

Back Pocket

  • NotebookLM source pack export: .txt and URL first.
  • Private visual dashboard after usage is proven.
  • Google Calendar/iCloud CalDAV when school deadlines matter.
  • Notion import as source material, not the interface.

Close the Install Call

"For the next two days, don't try to use this perfectly. Just throw things at it. Ideas, links, reminders, random tasks, stuff you might want later. If it makes capture and recall easier, we build the visual layer. If it feels like another app to manage, we cut it down further."
