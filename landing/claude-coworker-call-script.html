Position Claude as coworker

Think of Claude less like a search box and more like a junior coworker with a great memory for the context you give it. It can draft, compare, summarize, organize, question your assumptions, and create first passes. It still needs direction and review.
Use Claude for
Drafts, summaries, research synthesis, SOPs, emails, planning, document review, checklists.
Do not use blindly for
Final legal/financial advice, facts without source checking, customer commitments, private data without approval.

The 4-part prompt

Role: You are helping me as [role]. Context: Here is what is going on: [background]. Task: I need you to [specific output]. Success: A good answer should [criteria, tone, format, length]. Before you answer, ask clarifying questions if anything important is missing.

Use this anytime he gets a bland answer. Most bad prompts are missing context or success criteria.

Useful Claude coworker modes

Clarifier

“Ask me questions before you answer.”

Editor

“Keep my voice. Fix clarity only.”

Operator

“Turn this into steps and a checklist.”

Analyst

“Compare these options and tell me the tradeoffs.”

Teacher

“Explain this like I’m new, then give me a practice task.”

Reviewer

“Find holes, risks, missing assumptions.”

Voice-preserving prompts

I like my voice in this. Do not make it sound corporate or over-polished. Only fix typos, clarity issues, and awkward transitions. Show me the cleaned-up version only.
Use this as a voice sample. Describe the writing style in 6 bullets. Then rewrite the next draft in that style without making it sound like marketing copy.

Meta prompt coaching loop

  1. Start with the messy idea.
  2. Ask Claude to improve the prompt before doing the task.
  3. Answer Claude’s questions.
  4. Save the final prompt if it will repeat.
  5. After output, ask: “What would you need next time to do this 20% better?”
Here is the result you gave me. Improve the prompt that would have produced a better version. Keep it reusable.

Guardrails to teach on the call

  • Give Claude examples whenever possible.
  • Tell it what not to change.
  • Ask for questions before answers on important work.
  • Ask for assumptions and risks.
  • Never paste sensitive client data unless the account/data policy allows it.
  • For facts, ask Claude to separate “known from source” from “inference.”
